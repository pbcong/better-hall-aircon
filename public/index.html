Open chrome://extensions or edge://extensions, enable Developer mode, click Load unpacked, and select this project’s extension folder. Then refresh this page.

The helper watches only this local app and Daikin’s return page. It has no permission to read NTU’s login page. Automatic capture in Safari on iPhone is not available in this local demo.

Connect manually instead
  1. Open the official NTU sign-in and sign in.
  2. Daikin may then show “Cannot GET /adfs/saml/redirect/…”. That’s expected.
  3. Copy that tab’s full address and paste it here.
How does sign-in work?

The button starts at Daikin, then opens loginfs.ntu.edu.sg. Enter your password only on NTU’s page. The final address ends in /adfs/saml/redirect/ followed by a login code; the server exchanges that code with Daikin for an aircon token, then checks your aircon before enabling controls.

The pasted address is never opened. Never paste your NTU password or SSO cookie, and keep the return address out of chats and screenshots.

Remembered aircon tokens are encrypted locally. Your NTU password is never saved.
