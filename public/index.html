What happens after NTU sign-in?

The button starts at Daikin, then opens loginfs.ntu.edu.sg. Enter your password only on NTU’s page. Daikin handles the NTU sign-in response.

The final address ends in /adfs/saml/redirect/ followed by a login code. The “Cannot GET” message can be ignored. Copy the full address into this form. The local server exchanges that code with Daikin for an aircon token, then checks your aircon status before enabling controls.

The pasted address is parsed locally and never opened. Only the login code is sent to Daikin’s fixed authentication endpoint. Never paste your NTU password or SSO cookie. Keep the full return URL out of chat and screenshots. Practice mode works without signing in.
